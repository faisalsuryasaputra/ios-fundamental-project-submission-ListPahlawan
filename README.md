# 🇮🇩 Heroic: Indonesian National Heroes Directory

A fundamental iOS application developed as a final project for the iOS Developer path at Dicoding. This app serves as a digital directory to honor and learn about Indonesian National Heroes through a clean and responsive user interface.

## 🚀 Key Features
* **Hero Directory**: Displays a curated list of at least 10 Indonesian heroes with their images and short descriptions.
* **Biographical Details**: A dedicated detail page for each hero, providing a deeper look into their history and contributions.
* **Developer Profile**: A dedicated section featuring the developer's credentials as a Telkom University student.
* **SwiftUI Architecture**: Built using a modern declarative approach for seamless navigation and adaptive layouts.

## 🛠️ Tech Stack
* **Language**: Swift
* **UI Framework**: SwiftUI
* **Design Pattern**: MV (Model-View)
* **IDE**: Xcode
